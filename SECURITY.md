# Security policy

## Supported versions

| Version | Supported |
|---|---|
| Latest release on `main` | Yes |
| All other releases | No |

Only the latest published release receives security updates. There is no backport policy at this time.

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/coacopacoXR/viewpoint-arena/security/advisories/new):

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the advisory form with as much detail as you can provide.

If you are unable to use GitHub Security Advisories, contact the maintainers at the address listed in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## What to include

When reporting a vulnerability, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept.
- The version(s) of the project affected.
- Any suggested remediation, if you have one.

## Response timeline

We aim to:

- **Acknowledge** receipt of your report within **72 hours**.
- Provide an **initial assessment** within **7 days**, including severity and next steps.
- Deliver a **fix or mitigation** within **30 days** for critical and high severity issues.

If you do not receive a response within the acknowledgment window, please follow up at the enforcement contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Disclosure

We follow coordinated disclosure. Once a fix is available, we will:

1. Publish a security advisory on GitHub.
2. Release a patched version.
3. Credit the reporter (unless they request anonymity).

We ask that you do not publicly disclose the vulnerability before we have had a reasonable period to address it.
