# docs/

- [`INSTALL.md`](INSTALL.md): install and run the whole app on your own
  machine with Docker, step by step.
- [`supabase-schema.sql`](supabase-schema.sql): the database schema. It works
  against any Postgres, not only hosted Supabase.
- [`adapters/`](adapters/): how to point the app at your own services
  (notifications and other connectors).

The root [`README.md`](../README.md) has the feature tour, and
[`CONTRIBUTING.md`](../CONTRIBUTING.md) explains how to build and test it.
